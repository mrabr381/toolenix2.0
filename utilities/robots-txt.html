What is robots.txt?

robots.txt is a plain text file at your domain root (yourdomain.com/robots.txt) that implements the Robots Exclusion Protocol. It tells well-behaved web crawlers which parts of your site to access and which to skip.

robots.txt syntax

  • User-agent: * — applies to all crawlers. Use a specific bot name (Googlebot, Bingbot, GPTBot) to target one crawler.
  • Disallow: /path/ — prevents crawling of this path and all paths below it.
  • Allow: /path/ — explicitly allows a path even within a broader Disallow. More specific rules take precedence.
  • Sitemap: https://… — tells crawlers where your XML sitemap is located. Can appear multiple times.
  • Crawl-delay: N — asks crawlers to wait N seconds between requests. Not supported by Googlebot.

Important limitations

robots.txt is not a security mechanism. It's a voluntary protocol. Malicious scrapers ignore it entirely. Sensitive content must be protected by authentication — not robots.txt. Additionally, Googlebot may still index a URL it can't crawl if it finds links to that URL elsewhere.

Common patterns

  • Block all crawlers from admin areas — Disallow: /admin/
  • Block AI training crawlers — use User-agent: GPTBot / Disallow: / and similar rules for CCBot, Google-Extended, etc.
  • Block duplicate content — Disallow: /?sort= to block URL parameters that create duplicate pages
