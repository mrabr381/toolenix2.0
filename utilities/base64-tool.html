What is Base64?

Base64 is a binary-to-text encoding scheme that represents binary data using 64 printable ASCII characters (A–Z, a–z, 0–9, +, /). It was designed to safely transmit binary data through channels that only support text — such as email protocols, JSON, XML, and HTTP headers.

Common uses

  • Data URLs — embedding images directly in HTML or CSS: src="data:image/png;base64,…"
  • HTTP Basic Auth — credentials are Base64-encoded in the Authorization header
  • JWT tokens — the header and payload sections are Base64url-encoded JSON
  • Email attachments — MIME protocol encodes attachments as Base64
  • API payloads — encoding binary data for JSON transmission where binary fields aren't supported

Base64 is encoding, not encryption. Anyone with the encoded string can decode it instantly. Never use Base64 to obscure sensitive data — use proper encryption for that.

Unicode support

Standard Base64 functions in JavaScript (btoa/atob) only handle Latin-1 characters. Toolenix uses encodeURIComponent + unescape to correctly handle Unicode text including emoji, Chinese characters, and other multi-byte characters.
