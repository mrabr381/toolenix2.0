Format comparison

  • JPG — Lossy compression. Best for photographs and complex images. Smallest file size. Does not support transparency.
  • PNG — Lossless. Best for screenshots, logos, and images requiring transparency. Larger file sizes for photos.
  • WebP — Google's modern format. 25–35% smaller than JPG/PNG at equivalent quality. Supports both lossy and lossless. All modern browsers support it.

Transparency handling

PNG and WebP support transparent backgrounds. If you convert a transparent PNG to JPG, the transparent area becomes white — JPG does not support an alpha channel. To preserve transparency, convert to PNG or WebP.

When to use each format

  • Photographs for web → WebP (best compression) or JPG (broadest compatibility)
  • Logos and UI elements → PNG (transparency) or WebP
  • Screenshots → PNG (lossless, sharp text)
  • Email images → JPG (broadest client support)
