Understanding password entropy

Entropy (measured in bits) quantifies how unpredictable a password is. Each additional bit doubles the number of guesses required. The formula is: bits = log2(pool_size) × length. A 16-character password using all character types has roughly 105 bits of entropy — against a modern GPU cluster running 10 billion guesses/second, that's still trillions of years to brute-force.

Why "p@ssw0rd" is weak even with symbols

Attackers don't only brute-force. They use dictionary attacks with known substitution patterns (a→@, o→0, e→3). A 10-character word with predictable substitutions has far less effective entropy than its character pool suggests. True randomness — generated by a machine, not a human — is always stronger than a memorable pattern.

This tool's limitations

This tool analyses password structure and calculates theoretical entropy. It does not check against breach databases. For that, use Have I Been Pwned (haveibeenpwned.com) — they use k-anonymity so your password is never transmitted in full.
