What is a UUID v4?

A UUID (Universally Unique Identifier) is a 128-bit identifier. Version 4 is randomly generated — 122 of the 128 bits are random, with 6 bits reserved to mark the version and variant. The standard representation is 32 hexadecimal characters split into five groups by hyphens: xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx.

Collision probability

The probability of generating two identical UUID v4s is astronomically small. To have a 50% probability of a single collision, you'd need to generate approximately 2.7 × 10¹⁸ UUIDs — roughly one billion UUIDs per second for 85 years. For all practical purposes, UUID v4 values are globally unique.

Common uses

  • Database primary keys — UUID keys work in distributed systems where auto-increment integers from a single sequence would cause conflicts
  • API idempotency keys — prevent duplicate request processing in payment systems and critical APIs
  • File names — guarantees unique filenames for uploaded assets without collision risk
  • Session identifiers — random, unforgeable identifiers for user sessions
  • Correlation IDs — trace a single request through distributed microservices logs

Toolenix uses crypto.randomUUID() — a native browser function using cryptographically secure randomness. No library required, no network call needed.
