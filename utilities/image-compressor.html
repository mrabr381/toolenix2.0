How browser-based image compression works

Toolenix draws your uploaded image onto an HTML Canvas element, then exports it using the Canvas toBlob() API at your chosen quality level. This applies lossy JPEG or WebP compression — removing perceptually insignificant data to reduce file size while maintaining visual quality.

Quality guide

  • 80–90% — Best balance. Visually indistinguishable from the original for most images at significantly smaller file size.
  • 60–79% — Noticeable on close inspection. Suitable for web thumbnails and previews.
  • Below 60% — Visible JPEG artefacts. Only for very small preview images.

PNG compression caveat

PNG is lossless. Compressing a PNG at "80% quality" via Canvas converts it to the selected output format. To retain PNG format with lossless compression, the savings will be minimal compared to a dedicated tool like pngquant. For maximum PNG compression, convert to WebP instead — WebP typically achieves 25–35% smaller files than PNG at equivalent quality.

WebP for web images

WebP is Google's modern image format. It achieves 25–35% smaller file sizes compared to JPEG at equivalent quality, and supports both lossy and lossless compression. All modern browsers support WebP. If you're optimising images for a website, converting to WebP is the most effective single change you can make.
