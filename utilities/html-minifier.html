What HTML minification removes

  • HTML comments — <!-- … --> blocks add no value to the browser and can be removed safely in production.
  • Whitespace between tags — multiple spaces, newlines, and indentation between elements are collapsed to single spaces. This is safe for block elements but can affect inline elements in edge cases.
  • Optional attribute quotes — attribute values without spaces, quotes, or special characters don't require quotes in HTML5. class="nav" can become class=nav. This is aggressive and should be tested.

Typical savings

Whitespace removal typically yields 5–20% size reduction depending on how the original was formatted. Combined with server-side gzip/Brotli compression (which all modern web servers provide), minification provides a smaller but still meaningful additional reduction — typically 3–8% on top of compression.

Always minify in your build process (Webpack, Vite, Parcel, Gulp) rather than manually. Automated minification is error-free, runs on every build, and can apply more aggressive optimisations safely.
