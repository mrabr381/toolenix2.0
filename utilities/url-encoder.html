encodeURIComponent vs encodeURI

  • encodeURIComponent — encodes everything except letters, digits, and - _ . ! ~ * ' ( ). Use this for encoding individual query parameter values before inserting them into a URL string.
  • encodeURI — encodes all characters except those that are valid URL structural characters: : / ? # [ ] @ ! $ & ' ( ) * + , ; =. Use this for encoding a complete URL while preserving its structure.

When you need URL encoding

Any user-provided text that gets appended to a URL must be encoded. Spaces become %20 (or + in form data), ampersands become %26, equals signs become %3D. Without encoding, these characters break URL parsing — a query string like q=a&b would be interpreted as two parameters rather than one.

Decoding

This tool uses decodeURIComponent with +-to-space conversion for form-encoded input. If you receive a URL-encoded string from a form submission, the + character represents a space and must be converted before decoding percent sequences.
