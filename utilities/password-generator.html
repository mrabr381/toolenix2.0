What makes a password truly strong?

Password strength is primarily a function of entropy — how many possible combinations an attacker must try. Entropy scales with length exponentially and character pool size logarithmically. This means length matters more than complexity.

  • Length — the single most important factor. A 20-character lowercase-only password beats an 8-character mixed-case password by orders of magnitude.
  • Character variety — mixing uppercase, lowercase, numbers, and symbols expands the character pool, increasing entropy per character.
  • True randomness — Toolenix uses crypto.getRandomValues(), the Web Crypto API. This is cryptographically secure — unlike Math.random() which is not suitable for security use.
  • Uniqueness — using the same password across accounts means one breach exposes everything. Use a password manager to maintain unique passwords for every service.

Password length recommendations by use case

  • General accounts — 16 characters minimum
  • Financial accounts, email — 20+ characters
  • Admin/root passwords, encryption keys — 32+ characters
  • Master password manager password — 20+ characters, memorised, not stored anywhere digital

Never store passwords in plain text files, spreadsheets, or browser notes. Use a dedicated password manager: Bitwarden (free, open-source), 1Password, or KeePass.
