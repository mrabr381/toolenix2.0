Case format reference

  • UPPERCASE — all characters capitalised. Used for headings, constants in code, acronyms, SHOUTING.
  • lowercase — all characters lowercased. Used for email addresses, URLs, CSS property values.
  • Title Case — first letter of each word capitalised. Used for headings, book titles, proper names.
  • Sentence case — only the first word capitalised. Standard for prose, UI labels, and most body text.
  • camelCase — words joined, each after the first capitalised. Standard for JavaScript variables and function names.
  • PascalCase — like camelCase but first word also capitalised. Used for class names in JavaScript, Java, C#.
  • snake_case — words joined with underscores, all lowercase. Standard in Python, SQL column names, file names in many projects.
  • kebab-case — words joined with hyphens, all lowercase. Used in CSS class names, HTML attributes, URL slugs.
  • CONSTANT_CASE — uppercase snake_case. Used for constants and environment variable names in most languages.
