How PDF to JPG conversion works

PDF.js renders each page onto an HTML Canvas at your chosen scale, then exports the canvas as a JPEG at your chosen quality level. Higher scale produces sharper images suitable for print. Lower scale produces smaller files for web use.

Scale and quality guide

  • 2x scale, 95% quality — best for printing or archiving; largest file size
  • 1.5x scale, 85% quality — good balance for sharing and web use
  • 1x scale, 70% quality — smallest output; suitable for thumbnails

Common use cases

Extracting images from PDF for web publishing, creating thumbnails from document pages, converting PDF slides to image format for social media, or making non-editable image versions of sensitive documents.
