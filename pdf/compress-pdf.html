Why compress a PDF?

Large PDFs cause problems: email attachments get rejected, cloud storage fills up, and page load times suffer. Compressing a PDF removes unnecessary data — embedded metadata, duplicate objects, and unoptimised object streams — making the file smaller without touching the visible content.

Honest expectation: what client-side compression can and cannot do

Toolenix's compressor uses pdf-lib to strip metadata, remove unused objects, and pack object streams more efficiently. This works well on PDFs that are unoptimised at creation (many Word-to-PDF exports, for example). However, a PDF that already contains compressed JPEGs and was previously optimised may see only modest size reduction. For aggressive image downsampling, a server-side compressor is more effective — but that means uploading your file to someone else's server.

If size reduction is less than expected, the PDF was likely already well-optimised. Your file content is always preserved exactly as it was.
