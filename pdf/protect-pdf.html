Why password-protect a PDF?

Password protection prevents unauthorised access to sensitive documents. A user password restricts who can open the file. An owner password restricts editing, printing, and copying. Both can be set simultaneously for maximum protection.

Toolenix uses pdf-lib's encryption support to apply standard PDF password protection entirely client-side — the unencrypted file never leaves your device.
